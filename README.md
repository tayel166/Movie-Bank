# 🎬 Movie Bank

**Movie Bank** is a dynamic movie streaming website built with **HTML**, **CSS**, **JavaScript**, **PHP**, and **Firebase**.  
It provides users with an interactive interface to browse, view, and play movie data in a sleek and responsive design.

---

## 📖 Project Overview

Movie Bank is a front-end and back-end integrated web application that simulates a movie streaming platform.  
The front-end (HTML, CSS, JS) is responsible for layout and user interaction, while the back-end (PHP and Firebase) handles data storage, authentication, and server logic.  

This project was built to enhance understanding of full-stack web development and connecting Firebase services with a PHP-based environment.

---

## 🧩 Features

- 🎞️ Browse and explore movie categories
- 🎥 Watch official movie trailers directly on the site  
- 🔐 Firebase authentication for user login/signup  
- ☁️ Store and fetch data using Firebase  
- 💻 Responsive and modern user interface  
- ⚡ PHP integration for dynamic functionality
